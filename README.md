## Описание

F1 Hub — информационный сайт о Формуле-1 с базой пилотов и команд, характеристиками болидов и возможностью оформления заявки на билеты.

## Практическая работа №9

Создан отдельный проект на Bootstrap 5.3.8.

Реализованы:
- Подключение Bootstrap через CDN
- Собственный файл css/custom.css
- Навигационная панель
- Hero-блок
- Bootstrap-сетка
- Блок особенностей сезона 2026
- Карточки билетов на Гран-при
- Информационный блок
- Подвал страницы
