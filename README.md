## Описание проекта

F1 Hub — многостраничный информационный сайт, посвящённый Формуле-1. Проект предоставляет информацию о пилотах и командах, технических характеристиках болида Red Bull Racing RB22, а также содержит форму оформления заявки на билеты Гран-при.

Контрольная работа №2 представляет собой отдельную реализацию предметной области КР №1 с использованием CSS-фреймворка Bootstrap 5.3.8.

## Используемые технологии

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript
- Git и GitHub

Bootstrap подключён через CDN. Дополнительные стили размещены в файле `css/custom.css`.

### Использованные Bootstrap-компоненты

| Компонент | Назначение |
|---|---|
| navbar | Навигация между страницами |
| card | Карточки пилотов, команд и билетов |
| btn | Кнопки действий и переходов |
| badge | Цветные обозначения команд |
| alert | Информационные сообщения |
| modal | Модальное окно |
| accordion | Частые вопросы о RB22 |
| form-control | Поля формы заявки |
| form-select | Выбор Гран-при и категории билетов |
| input-group | Группа ввода телефонного номера |
| form-check | Подтверждение согласия |
| table | Характеристики болида |
| breadcrumb | Навигационная цепочка |

Для работы интерактивных Bootstrap-компонентов подключён `bootstrap.bundle.min.js`.

## Запуск проекта

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта в Visual Studio Code.
3. Открыть `index.html` через Live Server или обычный браузер.
4. Для корректного подключения Bootstrap через CDN требуется доступ к интернету.

Установка дополнительных пакетов не требуется.
